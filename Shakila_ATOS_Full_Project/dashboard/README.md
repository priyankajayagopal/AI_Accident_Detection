# ATOS dashboard
Vanilla HTML/JS (no npm build) in `atos_dashboard/public/index.html` + `src/app.js`, served by the FastAPI server at `/`.
Modules (slide 14): Live Video, Incident Panel, Traffic Panel, Map View, Agent Monitor, Alerts, Reports, Camera Grid (+ simulation chart).
Chosen over React for the 2-day timeline: zero build tooling, identical API/WebSocket contract, can be ported to React later.
