# Limitations (state these openly in the viva)
1. **Data:** the shipped experiments use *synthetic* CCTV-style overhead videos with exact ground truth (generated by `tools/synthetic_video.py`). Metrics
   therefore show the *pipeline works and is testable*, they are NOT field accuracy. For the thesis, repeat `scripts.process_video --detector yolo` +
   `scripts.train_models` on CADP / DoTA / UA-DETRAC clips (dataset shift, dashcam vs CCTV, is a stated risk).
2. **Detector:** the synthetic demo uses a colour-segmentation detector; real footage uses YOLO (`pip install ultralytics`). Tracker is a ByteTrack-style implementation, not the reference one.
3. **VLM:** default `mock` backend is an independent image-analysis stand-in. Real VLM backends (Claude / Gemini) are implemented behind strict schema validation but need API keys and were not benchmarked.
4. **Severity labels** come from the slide-10 rule table (no public CCTV severity labels) - the model learns the table; replace with CCD-derived labels for the thesis.
5. **Simulation:** built-in microsimulator (IDM, 5-junction corridor) rather than SUMO; results depend on stated assumptions (demand, VMS compliance, clearance 300 s after responder arrival, 150 s manual-report delay).
6. **No physical signal actuation**, single-corridor scope, no night/rain/fog evaluation, single camera (no multi-camera fusion).
7. LLM latency/cost stays outside the real-time path; local-model fallback = `rule` backend.
